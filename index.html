Cómo se usa

Pasos

  1. Refresca la consulta. Abre "VENTAS EN TIEMPO REAL (CONSULTA SQL).xlsx" en Excel, actualiza la consulta de la hoja Consulta1 y guarda el archivo.
  2. Arrastra ese mismo .xlsx a la zona de carga de esta página (o haz clic ahí y elígelo). No hace falta exportar CSV ni copiar/pegar nada — la página lee el archivo tal cual.
  3. Espera unos segundos. Con archivos grandes (100.000+ filas) la lectura puede tardar un momento; el mensaje bajo la zona de carga avisa cuántas líneas quedaron cargadas.
  4. Revisa las tres pestañas: "Insumos consumidos" (materia prima total, costo y en cuántos platos aparece), "Platos vendidos" (cada producto con su receta cruzada y %CMV) y "Sin receta" (productos de alimentos/bebidas que no se pudieron cruzar — para revisar el nombre manualmente).
  5. Filtra o busca para acotar la vista, y usa "Descargar CSV" en cualquier tabla si necesitas llevar los datos a Excel.

Filtros disponibles

Buscador
Escribe el nombre de un insumo o un plato; al escribir aparecen sugerencias reales de lo cargado — haz clic en una para ir directo a ese artículo.
Grupo
La categoría que ya trae el punto de venta (CARNES, PICADAS, CERVEZAS...). Lista con casillas, se puede marcar varios.
Centro
El punto de venta o cocina donde se facturó (REST, PIZZA, BARL, GYM...).
Tipo
Alimentos, Bebidas u Otros (no A&B, como golf o membresías).
Desde / Hasta
Acota el período. Arranca mostrando todo el rango de fechas que trae el archivo cargado.

Sobre el cruce

Cada línea de venta se cruza contra el libro de recetas por el código exacto de fórmula (columna Codigo_inv del archivo de ventas) — no por el nombre del plato, que puede variar entre sistemas. Si el producto no tiene fórmula pero sí un código de inventario (por ejemplo una cerveza que se vende tal cual), se cuenta directamente como su propio insumo. Solo cuando no hay ni código ni fórmula se recurre a un cruce aproximado por nombre, y ese caso queda marcado como "por nombre" en la columna Cruce.

Esta página no tiene conexión en vivo a ninguna base de datos: cada vez que quieras cifras nuevas, repite los pasos 1 y 2.
